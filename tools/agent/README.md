# Agente autónomo

Agente de pentesting autónomo con LLM local para entornos de baja capacidad de cómputo.

## Objetivo

Orquestar herramientas de seguridad (vía MCP) con razonamiento asistido por modelo de lenguaje local, como parte del **Caso 1 — Pentesting agéntico**.

## Estado

En desarrollo. El código se publicará aquí conforme avance la implementación.

## Referencias

- Frameworks de referencia: CAI, Bug-TraceAI
- Cliente agente relacionado: `agent-client` en el servidor MCP
